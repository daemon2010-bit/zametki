# Заметки (Windows + Android)

Кроссплатформенное приложение для личных заметок с локальным хранением, темной/светлой темой, русским и английским интерфейсом, офлайн-обменом и синхронизацией.

## Структура проекта

- `new/` - десктопная версия для Windows (Python 3.13, PySide6, PyInstaller).
- `android/` - мобильная версия для Android (Kotlin, Jetpack Compose, Material 3).

## Основные возможности

- Форматирование текста, маркированные и нумерованные списки, интерактивные чек-листы, вставка изображений (Windows).
- Цветовые метки, `#теги`, поиск, закрепление заметок, корзина с защитой от случайного удаления и автоочисткой через 30 дней.
- Обмен заметками:
  - файл `.zametka` (ZIP-пакет, удобно пересылать через мессенджеры);
  - офлайн QR-код (передача с ПК на Android без Wi-Fi и интернета, сканирование камерой и из фото/скриншота);
  - локальная синхронизация по Wi-Fi (ПК <-> Android);
  - облачная синхронизация через WebDAV.
- Поддержка русского и английского языков (`RU` / `EN`) и тем оформления (`Система` / `Светлая` / `Темная`).

## Сборка

### Windows (`new/`)
```powershell
cd new
python -X utf8 -u tests/smoke.py
python -m PyInstaller --noconfirm Заметки.spec
```
Результат: `new/dist/Заметки.exe`.

### Android (`android/`)
```powershell
cd android
gradle assembleRelease --no-daemon
```
Результат: `android/app/build/outputs/apk/release/app-release.apk`.
