# task.md — Переделка приложения «Заметки»

## Цель
Пересобрать приложение заметок (стиль Apple Notes, Windows, офлайн) с модульной архитектурой и функциональностью пакетов A+B+C+D. Старый `Заметки.exe` остаётся нетронутым до явного решения пользователя о замене.

## Приоритеты (задано пользователем 11.11.2026)
**Максимальная стабильность, надёжность, скорость, компактность.** Функциональность — не в ущерб им: каждая фича реализуется самым простым надёжным способом; сомнение — в пользу простоты.

## Принципы
1. **Совместимость данных:** читаем и пишем `%APPDATA%\Заметки` в текущем формате (JSON на заметку, `folders.json`, `settings.json`). Новые поля (цвет, вложения, напоминания, версии) добавляем так, чтобы старый exe их игнорировал и не ломался.
2. **Только офлайн:** никаких сетевых отправок. Всё хранится локально.
3. **Без сторонних зависимостей сверх PySide6:** глобальный хоткей — через ctypes `RegisterHotKey`; single-instance — через `QLocalServer`; уведомления — `QSystemTrayIcon.showMessage`.
4. **Стабильность:** атомарная запись (`.tmp` + замена) везде; при старте — восстановление недописанных `.tmp`; сбой одной заметки не валит приложение (защита в отрисовке списка/редактора); `crash.log` сохраняется; перед сборкой — ручной чек-лист проверок.
5. **Компактность/скорость:** в exe включаем только QtCore/QtGui/QtWidgets (без QtNetwork, QtSvg, QtMultimedia и прочего); сжатие LZMA; цель — размер не больше текущего (~45 МБ) и запуск в ту же секунды-полторы. Замеры делаем до и после.
6. **Лёгкие реализации:** цветные метки заметок вместо полноценной системы тегов; история версий — простые снапшоты с жёстким лимитом (последние ~20 на заметку).

## Технологии
- Python 3.12 (или доступный 3.13/3.14 — проверить совместимость PySide6), PySide6 — нужна установка через pip (требует разрешения).
- Сборка: PyInstaller onefile, портативный exe без установки, имя и иконка — как у текущего.

## Архитектура (пакет `zametki/`)
- `main.py` — точка входа, single-instance, применённая тема.
- `core/store.py` — хранилище: заметки (JSON per note), папки, настройки; атомарная запись через `.tmp`; миграция старых данных.
- **Папка данных (по поручению 11.11.2026):** по умолчанию `%APPDATA%\Заметки` на диске C (совместимо с текущими заметками). Переназначение — удобно, из самого приложения: настройки → «Папка данных»: текущий путь, «Выбрать папку…», «Открыть в проводнике», «Вернуть обычную». При смене: проверка папки (существует, тест-запись) → предложение перенести заметки (копирование с проверкой результата; старая папка остаётся как резервная копия) → перезапуск без потери несохранённого. Указатель переназначения — файл `data-location.txt` в папке по умолчанию; переменная `ZAMETKI_HOME` сохраняется как старший приоритет (совместимость). Если папка недоступна при запуске — сообщение об ошибке и диалог выбора, данные не трогаем.
- `core/models.py` — структуры заметки/папки; расширение схемы: `color`, `attachments`, `reminder_at`, список версий.
- `core/versions.py` — история версий: снапшоты в `versions/<note-id>/`, ротация (последние ~50).
- `core/backup.py` — автобэкап папки данных: ежедневно, ротация 7 копий в `%APPDATA%\Заметки\backups`.
- `core/attachments.py` — картинки: файлы в `%APPDATA%\Заметки\attachments\<note-id>\`.
- `core/single.py` — one-instance через `QLocalServer`/`QLocalSocket`.
- `core/hotkey.py` — глобальная горячая клавиша (ctypes RegisterHotKey, настраиваемая).
- `ui/main_window.py` — три панели: папки/теги, список, редактор; трей.
- `ui/notes_list.py` + `ui/delegates.py` — список, сортировка, галерея-режим, цветные точки.
- `ui/editor.py` — редактор: форматирование, чек-листы (QTextListFormat.MarkerType, Qt 6.7+), картинки, ссылки Ctrl+K, заголовки H1–H3, цвет текста/маркер.
- `ui/export.py` — экспорт PDF (QPrinter), HTML, TXT, Markdown; импорт TXT/HTML (и перетаскиванием).
- `ui/search.py` — поиск с подсветкой найденного в списке.
- `ui/theme.py` — светлая/тёмная/системная тема (QSS + палитра).
- `ui/reminders.py` — напоминания: QTimer + системные уведомления через трей.

## Фазы (порядок работ)
> **Статус 11.11.2026:** фазы 0–D реализованы, автопроверки 20/20, exe собран (`new\dist\Заметки.exe`, 45,2 МБ) и проверен на запуск. Чек-лист ручной проверки — `new\Проверка.md`. Фаза E — не выполнялась.

- **Фаза 0 — каркас:** окно, Store, все текущие функции один в один (папки, корзина, pin, поиск, форматирование, даты). Критерий: по функциям не хуже старого exe, старые заметки открываются. ✔
- **Фаза A «Каждый день»:** чек-листы с кликабельными чекбоксами; вставка картинок из буфера и файлов, вложения; тёмная/системная тема; сортировка (по дате изменения/создания/названию).
- **Фаза B «Переносимость»:** экспорт PDF/HTML/TXT/MD; импорт TXT/HTML; автобэкап с ротацией; блокировка второго экземпляра.
- **Фаза C «Организация»:** цветные метки заметок (5–7 цветов, фильтр по клику), история версий с откатом (лимит ~20), подсветка найденного.
- **Фаза D «Windows»:** иконка в трее, свернуть в трей; глобальный хоткей «быстрая заметка»; напоминания-уведомления. Автозапуск — отдельная настройка, включать только по явному поручению.
- **Фаза E (по желанию, после A–D):** таблицы, печать, отдельное окно заметки.

## Не делаем (осознанно, решение пользователя)
OCR, импорт ENEX/Evernote, защита заметок паролем, шифрование/E2E, мобильная версия, собственное облако — не нужны либо несопоставимая сложность. Синхронизация (фаза E+) — отдельная задача в новом чате.

## Критерии приёмки
- Все пункты фаз 0–D работают вручную по чек-листу проверок (составим к каждой фазе).
- Старые заметки/папки/настройки читаются, ничего не теряется.
- Сборка exe запускается на чистой машине без Python.
- `crash.log` продолжает писаться при сбоях.

## Риски
- PySide6 под доступный Python (3.14) — проверить версию поддержки; при несовместимости поставить Python 3.12/3.13 (с разрешения).
- Глобальный хоткей может конфликтовать с занятыми клавишами — сделать настраиваемым.
- Напоминания не срабатывают, если приложение закрыто — честно указать в справке (трей держит приложение в фоне).
