# «Заметки» — анализ приложения и предложения по улучшению

Дата: 11.11.2026. Всё, что помечено «Проверено», получено из разбора байткода exe, файлов данных и веб-исследования. Оценки трудоёмкости — предположения.

---

## 1. Что это за приложение (Проверено)

- **Стек:** Python 3.12 + PySide6 (Qt 6), упаковано PyInstaller в один exe (~45 МБ, из них ~44 МБ — библиотеки Qt).
- **Исходников в папке нет** — только `Заметки.exe` и `Прочти меня.txt`. Код приложения — один скрипт `app` (~1150 строк, 88 классов/функций), извлечён из exe.
- **Данные:** `%APPDATA%\Заметки` — каждая заметка отдельным `*.json` (id, folder, title, html, plain, snippet, created, modified, deleted, deleted_at, pinned), плюс `folders.json` и `settings.json` (геометрия окна, видимость панели). Резервная копия = скопировать папку.
- **Автосохранение** при печати через таймер; сохранение атомарное (через `.tmp`). При сбоях пишется `crash.log`.
- Служебные материалы разбора сохранены в папке `_rework` (извлечённые модули, справочник функций и строк кода).

## 2. Текущая функциональность (Проверено по коду)

| Есть | Нет |
|---|---|
| 3-панельный интерфейс в стиле Apple Notes (папки → список → редактор) | Вставка изображений и вложений |
| Папки: создание, переименование, удаление (с перемещением в корзину) | Чек-листы, таблицы, код-блоки |
| Заметки: создание (Ctrl+N), удаление в корзину, восстановление, удаление навсегда, дублирование | Теги, цветные метки |

| Поиск (Ctrl+F) по названию/тексту | Печать и PDF |
| Форматирование: полужирный, курсив, подчёркивание, зачёркнутый, маркированный список, выравнивание | Тёмная тема (палитра светлая зашита в код) |

| Корзина «Недавно удалённые» | История версий заметки |

## 3. Что мы можем с ним сделать

Исходники можно вернуть: байткод извлечён и читается. Два пути (Проверено: оба технически возможны):

1. **Реконструкция исходника** — восстановить читаемый Python из дизассемблированного байткода и дальше править. Плюс: сохраняется всё как есть. Минус: трудоёмко (оценка: несколько часов), код останется монолитным (~1150 строк в одном файле), что затруднит крупные доработки.
2. **Чистая переработка (рекомендую)** — новый проект по карте функций: та же логика и данные, аккуратная модульная архитектура (store / ui / editor), существующие заметки в `%APPDATA%\Заметки` подхватываются без изменений (формат JSON совместим). Минус: возможны мелкие отличия поведения — надо прогнать по чек-листу функций.

Сборка обратно в exe — стандартно через PyInstaller (та же схема, портативный exe без установки).

## 4. Аналоги: краткая сводка (Проверено — веб-исследование, 2025–2026)

| Приложение | Сильные стороны | Ограничения |
|---|---|---|
| Google Keep | чек-листы, OCR, метки, бесплатно | нет Windows-приложения, экспорт только Takeout |
| OneNote | свободный холст, таблицы, рисование, пароль на секцию, экспорт PDF/DOCX | тяжёлый, нет pin страниц |
| Apple Notes | чек-листы, сканы, аудио+транскрипция, блокировка заметок, теги | экосистема Apple |
| Obsidian | markdown, плагины, данные — локальные .md, бесплатно | нет синхронизации бесплатно, порог входа |
| Notion | блоки, базы данных, офлайн с 2025 | облако only, AI платный |
| Evernote | поиск по PDF/вложениям, задачи | Free сильно урезан (50 заметок, 1 устройство) |
| Joplin | open source, E2E-шифрование, синхронизация куда угодно, экспорт MD/PDF/HTML | интерфейс менее «вылизан» |
| Simplenote | бесплатно, синхронизация, история версий | только текст, разработка фактически заморожена |

**Обязательный минимум рынка** (есть почти у всех, отсутствует у нас): чек-листы; вставка изображений и вложений; экспорт в открытые форматы (PDF/HTML/MD); теги или цветные метки; сортировка; напоминания; синхронизация. E2E-шифрование — не минимум (есть лишь у Joplin/Standard Notes/Obsidian Sync).

## 5. Предложения: пакеты улучшений

**Пакет A — «Каждый день»** (оценка: средняя, ~1–2 вечера)
- Чек-листы с интерактивными чекбоксами (как в Apple Notes).
- Вставка изображений из буфера (Ctrl+V) и файлов, показ в тексте заметки.
- Тёмная тема + следование системной теме Windows.
- Сортировка списка заметок (по дате изменения/создания/названию).

**Пакет B — «Переносимость и надёжность»** (оценка: небольшая–средняя)
- Экспорт заметки в PDF, HTML, TXT, Markdown; импорт TXT/HTML (перетаскиванием тоже).
- Автоматическая резервная копия папки данных (ежедневная ротация, например 7 копий).
- Одна копия программы одновременно (блокировка второго экземпляра).

**Пакет C — «Организация»** (оценка: средняя)
- Теги заметок с фильтром по клику (или проще: цветные метки).
- История версий заметки (снапшоты при каждом изменении, откат).
- Улучшенный поиск: подсветка найденного, поиск по папке/тегу.

**Пакет D — «Интеграция с Windows»** (оценка: средняя; автозапуск — только по отдельному поручению)
- Иконка в системном трее, свернуть в трей.
- Глобальная горячая клавиша «быстрая заметка».
- Напоминания на заметку — системные уведомления Windows.
- Автозапуск с Windows (по желанию, настройкой внутри приложения).

**Пакет E — «Дальше»** (по отдельному плану): синхронизация между устройствами (через папку облачного диска — уже совместимо с хранением по файлам, или WebDAV), markdown-режим, таблицы, защита заметок паролем.

Не рекомендую: OCR по картинкам (нужны тяжёлые модели), мобильную версию, собственное облако — несопоставимая сложность для этого проекта.

## 6. Как продолжить

1. Выбрать путь переделки (реконструкция или чистая переработка).
2. Выбрать пакеты улучшений — от этого зависит архитектура.
3. После утверждения: план работ (`task.md`) → реализация → проверка → сборка нового exe (старый остаётся нетронутым до вашего решения о замене).

Данные не затрагиваются ни на одном шаге анализа: чтение шло только в сторону чтения, приложение не запускалось, `%APPDATA%\Заметки` только просмотрен.
